# Rol Pintoísta — herramientas de campaña

Herramientas para jugar Rol Pintoísta en vivo, cada uno desde su casa: mapa de
hexágonos con tokens, fichas de personaje, panel de combate del GM y generador
de tiendas. Todo se guarda y se comparte en tiempo real con Firebase.

## Cómo se usa

Se entra por el sitio publicado: <https://elsauloel.github.io/rolpintoista/>.
Desde ahí cada uno inicia sesión, elige su partida y abre el mapa, su ficha o
(el GM) GM Tools. No hace falta descargar nada.

## Ramas

- **`nueva-version`**: el sistema actual. Es la que se publica en el sitio:
  cada cambio que se sube sale publicado solo en uno o dos minutos.
- **`main`**: la versión vieja de la campaña «Piratas en el espacio», con
  sincronización manual por GitHub. Quedó archivada: no tiene ningún vínculo
  con el juego actual.
